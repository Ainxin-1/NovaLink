三、重要发现（必须记录）
------------------------------------------------------------------------
1. 许可证真相（修正预研报告）：
   sing-box LICENSE 为 GPL-3.0（或更高版本），另附加条款：
   "衍生作品不得使用本项目名称或暗示关联，除非获得事先同意"
   （GitHub API 识别为 NOASSERTION，实际文本已人工核阅）
   - Windows 端：以独立子进程方式启动核心，不构成代码合并，
     NovaLink 客户端代码不受 GPL 传染；不能在宣传中声称
     "由 sing-box 官方提供/认证"
   - Android 端：内嵌 libbox 库 = 库链接，APK 必须以 GPLv3 兼容
     方式开源。若不接受：备选 mihomo（MIT，允许闭源）
     -> 此为 Android 阶段开工前必须做出的产品决策

2. 免费节点可用性现状（印证预研坑#1）：
   - 40 个免费节点（443 端口优先、乱序、混合协议）从本机全部连接失败
     （dial tcp i/o timeout，含多个 Cloudflare/Fastly 边缘 IP）
   - 聚合器（GitHub Actions 美国环境）筛过的节点，换到用户实际网络
     环境即失效 -> 任务书第十四章"客户端设备端检测为主要参考"
     的设计被本次实测直接验证
   - 本机网络环境特殊：直连可达 Google/Cloudflare（疑似路由器级
     代理或运营商差异），且本机已运行 v2rayN(sing-box核心, PID 6372,
     端口 10808/10813)，节点测试结论受环境影响，换网络需复测

3. 链式验证说明：
   本次"真实连接"通过本机已有代理客户端的活节点完成，验证的是
   NovaLink 核心（sing-box 1.14.0）的启动、配置、入站/出站转发、
   停止恢复等集成机制；免费节点的协议握手（ss/trojan/vmess 出站
   直连）未能在本机网络环境完成实测，属于环境限制而非核心能力
   缺陷，阶段 2 节点管线开发中将在节点检测环节持续覆盖。
